# CS6983 Project 2 — Individual Reflection

*Haomiao Shi*

Working on Team Task Board Copilot taught me how to balance AI-assisted development with software engineering practices, especially when our team structure changed midway through the project.

During Sprint 1, Tyler and I collaborated on planning, implementation, and code reviews. We combined our individual AI coding guidelines into a shared AGENTS.md and divided tasks based on dependencies. Tyler focused on the database schema, authentication, and project APIs, while I worked on the Kanban board, CI/CD pipeline, and deployment. Our code reviews were valuable because we caught issues that automated tools did not immediately identify, including an open redirect vulnerability and responsive design problems.

Sprint 2 was different because Tyler left the course on November 6. With the professor's approval, I continued the project independently. I completed the remaining API integration, improved the UI, and implemented collaboration features such as shared projects, role-based permissions, task assignment, comments, and an activity feed. Working alone required me to manage priorities more carefully and rely on automated tests and documented self-reviews.

AI tools were an important part of my workflow. I primarily used GitHub Copilot Chat in VS Code for features and testing. Following our AGENTS.md guidelines, I used a test-driven development approach: writing failing tests first, implementing the functionality, and verifying the results through CI and end-to-end testing. However, I still needed to review AI-generated code, investigate failures, and make decisions about architecture and security.

My biggest takeaway is that AI can significantly accelerate development, but it does not replace engineering judgment. This project helped me become more confident in reviewing AI-generated code, managing a full-stack application, and taking responsibility for the final product.
